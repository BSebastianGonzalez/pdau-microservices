# Frontend reference

The frontend is a React/Vite application that consumes the PDAU APIs through the gateway. It is included here to explain the complete platform architecture, although it was not developed by the author of this documentation.

## Main areas

- Anonymous complaint registration with categories, evidence, and tracking token.
- Complaint consultation, responses, appeals, archived complaints, and statistics.
- Administrator login, password operations, profile data, and personal documents.
- Complaint review, comments, responses, status changes, archiving, indicators, and audit actions.

Source: [BSebastianGonzalez/pdau_frontend](https://github.com/BSebastianGonzalez/pdau_frontend)
